# Listening audio (optional)

Place recorded MP3 files here, named after the exercise id in `src/data/listening.ts`:

```
l-n5-shop.mp3
l-n5-weekend.mp3
l-n4-doctor.mp3
l-n4-office-request.mp3
l-n3-meeting-schedule.mp3
l-n2-complaint-call.mp3
l-n1-negotiation.mp3
l-biz-phone-absent.mp3
l-brse-daily-standup.mp3
l-it-incident.mp3
l-native-news.mp3
```

When a file is missing, the player reads the dialog line by line with the operating
system's offline Japanese speech-synthesis voice instead.
